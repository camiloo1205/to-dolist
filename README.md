# To-Do List en Python

Aplicación de consola para gestionar tareas.

## Funcionalidades

- Crear tareas
- Mostrar tareas
- Marcar tareas como completadas
- Eliminar tareas
- Establecer fecha de vencimiento
- Mostrar días restantes
- Guardar información en JSON

## Tecnologías

- Python
- JSON
- datetime

## Cómo ejecutar

python To-Dolist.py
